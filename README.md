# Samar Gharsallah | Portfolio

A responsive personal portfolio for **Samar Gharsallah**, an AI and Business Intelligence professional focused on AI adoption, enablement, automation, and data-driven decision-making.

## Preview locally

This is a dependency-free static site. Clone the repository and open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

In **Settings → Pages**, select **Deploy from a branch**, then choose the `main` branch and the `/ (root)` folder. GitHub Pages will publish the static site.

## Notes
